# Ludo (`ludo`)

Collection of **single-file HTML/CSS/JS Ludo prototypes** and experiments (“ludo with unique ideas”). No build step or package manager — open an HTML file in a browser.

## Quick start

```bash
python -m http.server 8080
```

Then open `http://localhost:8080/demos.html` for a catalog, or open any HTML file below directly.

## Main entries

| File | Title / role |
|------|----------------|
| `index.html` | Token Ludo: Legacy of Six |
| `ludo.html` | Smart Ludo Game – Enhanced |
| `kudo1600.html` | Ultimate Ludo Game (large prototype) |
| `gamedashboard.html` | Ultimate Ludo dashboard UI |
